## 1. 层叠上下文
##### 作用
层叠上下文，限制了绘制层级元素的范围：
若元素A创建了一个层叠上下文：
- 其所有子元素，整体上由`元素A的层级`决定。`元素A的层级`，取决于它在上一层的层叠上下文中的[绘制顺序](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/pKzJfZczuc/qElnKfiEEk/WjecWiE5Dl-oyC?block_id=docyg-2aebf6f0-5e2a-11f0-9fd7-e17d388e8d68)。
- 子元素间的层级，由[绘制顺序](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/pKzJfZczuc/qElnKfiEEk/WjecWiE5Dl-oyC?block_id=docyg-2aebf6f0-5e2a-11f0-9fd7-e17d388e8d68)决定。
##### 创建层叠上下文
文档根元素（html）具有层叠上下文
其他元素创建层叠上下文，有如下方法：
- position为relative或absolute，且 z-index不为auto
   - position为fixed或sticky
   - flex/grid的子元素，且z-index不为auto
   - opacity小于1
   - mix-blend-mode不为normal
   - isolation为isolate
> 更多创建层叠上下文的方法，详见: [MDN - 层叠上下文](https://developer.mozilla.org/zh-CN/docs/Web/CSS/CSS_positioned_layout/Stacking_context#%E5%B1%82%E5%8F%A0%E4%B8%8A%E4%B8%8B%E6%96%87)﻿
## 2. 绘制顺序
在一个层叠上下文内，遵循如下顺序（由后向前），绘制子元素：
1. 当前层叠上下文元素的背景与边框
2. 创建了层叠上下文的子元素，且层叠等级为负数（负数越大，越靠后）
3. 在普通文档流中的非定位、非内联子元素
4. 非定位float子元素
5. 在普通文档流中的非定位、内联子元素
6. 创建了层叠上下文的子元素或定位子元素，且层叠等级为0
7. 创建了层叠上下文的子元素，且层叠等级大于0（正数越大，越靠前）
> 详见：[W3C - z-index](https://www.w3.org/TR/CSS2/visuren.html#propdef-z-index)﻿
## 3. z-index 与层叠上下文的关系
其实层叠上下文并不完全依赖于z-index：
- 在不使用z-index的情况下，就能创建层叠上下文
- 绘制顺序也不完全依赖于z-index，即使元素没有z-index，浏览器还有着一套绘制顺序规则
但是z-index对于层叠上下文很重要，它是定制元素层级的抓手，它影响着[绘制顺序](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/pKzJfZczuc/qElnKfiEEk/WjecWiE5Dl-oyC?block_id=docyg-2aebf6f0-5e2a-11f0-9fd7-e17d388e8d68)中的第2、6、7条规则
## 4. z-index为auto/0
其实在层级上，z-index:auto 等于 z-index: 0；
但是，auto不会为当前元素创建层叠上下文
z-index: 0可以在一定条件下创建层叠上下文，以限制子元素的绘制顺序，详见[创建层叠上下文](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/pKzJfZczuc/qElnKfiEEk/WjecWiE5Dl-oyC?block_id=docyg-612b2420-5e2a-11f0-9fd7-e17d388e8d68)﻿
## 5. 例子
﻿[CodeSandBox - 层叠上下文例子](https://codesandbox.io/p/sandbox/p3cgs7)
﻿
```HTML
<div class="root">
    <div class="blue-box">
        <div class="yellow-box"></div>
    </div>
    <div class="red-box"></div>
</div>
```

```CSS
.root {
    .blue-box {
        width: 100px;
        height: 100px;
        position: relative;
        background: blue;

        .yellow-box {
            width: 50px;
            height: 50px;
            position: relative;
            top: 75px;
            z-index: 1;
            background: yellow;
        }
    }


    .red-box {
    width: 100px;
    height: 100px;
    position: relative;
    background: red;
    }
}
```

在blue-box没有创建层叠上下文的情况下，yellow-box与blue-box、red-box处于同一个层叠上下文。
由于yellow-box的z-index为1，yellow-box位于blue-box、red-box之上
![[Archives/Publish/CS/Css/assets/层叠上下文/image-1.png]]

当blue-box创建了层叠上下文，yellow-box作为blue-box的子元素，处于blue-box单独的层叠上下文中
yellow-box的z-index将影响它在blue-box的层叠上下文中的顺序，但是不会影响它在文档根元素html的层叠上下文顺序。
因此，会发现red-box覆盖yellow-box的一部分区域，这是因为：
- blue-box的绘制层级，低于red-box。因为两者都满足[绘制顺序](https://ku.baidu-int.com/knowledge/HFVrC7hq1Q/pKzJfZczuc/qElnKfiEEk/WjecWiE5Dl-oyC?block_id=docyg-2aebf6f0-5e2a-11f0-9fd7-e17d388e8d68)的规则6，按照声明顺序，red-box绘制层级高。
- yello-box作为blue-box层叠上下文中的子元素，绘制层级也低于red-box
![[Archives/Publish/CS/Css/assets/层叠上下文/image-2.png]]
