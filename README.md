# 个人笔记系统发布网站  


使用方法：
1. 将笔记内容放到content文件夹
2. 运行`npm run build`即可
3. 产物存放在`public`文件夹  

图片资源会被自动压缩，压缩算法在`./scripts/compress-images.mjs`文件夹
